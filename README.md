# MusicPlayer (Android)

YouTube / YouTube Music の曲を MP3 で保存し、ライブラリ・プレイリストで管理して再生できる個人用アプリです。
youtubedl-android(yt-dlp + FFmpeg 同梱)を端末内で動かします。ログインは不要です。

## 画面構成
- **ライブラリ**: ダウンロードした曲 + 指定フォルダ(既定: Music)の曲。YouTube Music 風に
  「フォルダ / 曲 / アルバム / アーティスト」をチップで切り替え。
  - フォルダ: 端末のフォルダ構成をツリー表示。タップで展開/折りたたみ、「すべて開く/閉じる」、フォルダごと再生
  - アルバム: ジャケットのグリッド → タップでアルバム内の曲一覧
  - 検索は全表示で横断(曲名・アーティスト・アルバム・フォルダ名)。検索中のフォルダ表示は一致する曲だけを展開表示
  - 下に引っ張ると再読み込み。読み込むフォルダはメニューの「ライブラリのフォルダ…」で追加・削除
  - 長押しで複数選択 → プレイリストに追加・削除・キューに追加
- **見つからないファイル**: 移動・削除された曲はグレー表示になり、再生時は自動でスキップします。
- **プレイリスト**: 作成・名前変更・削除。中身はドラッグ(≡)で並べ替え、左右スワイプで外す(元に戻す可)、
  「曲を追加」でライブラリから複数選択して追加。
- **ダウンロード**: キューの進行状況、中止・再試行、保存先の変更、yt-dlp の更新、詳細ログ。
- **曲を追加**(右下ボタン / 他アプリからの共有): 曲・アルバム・プレイリストの URL を入力。
  YouTube Music のアルバム URL はまとめてダウンロードし、同名のプレイリストを自動作成できます。
- **再生**: バックグラウンド再生、通知・ロック画面から操作可能。ミニプレーヤーをタップで再生画面
  (シーク、前/次、シャッフル、リピート)。

## おやすみタイマー / アラーム
- **おやすみタイマー**(画面上部の🌙・再生画面): 15分 / 30分 / 1時間 / 2時間 / 曲の終わりまで。最後の15秒をフェードアウト。
- **アラーム**(画面上部の⏰): 時刻・曜日(なしで1回のみ)・再生する曲 / プレイリスト / ライブラリ全体、
  シャッフル、徐々に音量アップ、音量、ラベル。鳴るとロック画面上に「スヌーズ(10分)」「停止」画面。
  端末の再起動・時刻変更後も自動で再登録。停止するとメディア音量を元に戻す。
- **ウィジェット**: シャッフル / リピート(オフ → 全曲 → 1曲)の切り替えボタン。

## アップデートについて
APK は固定の鍵で署名しています。同じ鍵で署名された APK は上書きインストールでき、
ライブラリ・プレイリストはそのまま引き継がれます。**この鍵を失くしたり変えたりしないでください。**
鍵はリポジトリには置かず、GitHub の Secrets(`KEYSTORE_BASE64`・`STORE_PASSWORD`・`KEY_ALIAS`・`KEY_PASSWORD`)から
ビルドの時だけ取り出します。手元でビルドする時は `keystore/ytmp3.jks` と `keystore/signing.properties` を置いてください
(どちらも `.gitignore` 済み)。

## ビルド
push すると GitHub Actions(`.github/workflows/build.yml`)が署名済み APK をビルドし、
公開用リポジトリのリリースに置きます(アプリ内の更新はそこから取得)。

## 注意
- 自分の動画、クリエイティブ・コモンズ等、権利のあるコンテンツに限って使ってください。YouTube の利用規約は無断ダウンロードを禁じています。
- YouTube 側の仕様変更で動かなくなることがあります。その場合はダウンロード画面の「更新」で yt-dlp を最新にしてください。
- minSdk 29(Android 10)。既定の保存先はダウンロードフォルダ(MediaStore)、任意フォルダは SAF 経由のため保存権限は不要です。
